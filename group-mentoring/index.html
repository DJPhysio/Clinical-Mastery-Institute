How it works

Same mentoring as 1:1,
built for your team.

Group sessions run exactly like 1:1 mentoring — structured, case-based, and focused on clinical reasoning — but with your whole team developing together in the same room.

Same clinic, same session

All participants are from the same practice. Sessions build shared clinical language and consistent reasoning frameworks across your whole team.

60 minutes, flexible schedule

Each session runs for 60 minutes via Google Meet. Frequency is flexible — weekly, fortnightly, or monthly, whatever suits the team's roster.

Structured case discussion

Each session works through a real clinical scenario. Every physio contributes their reasoning — nobody just observes.

Session summaries for everyone

A written summary and action plan is emailed to each physio after every session. Clinic owners also receive a copy.

What changes

When the whole team
learns together.

When multiple physios from the same clinic go through structured mentoring together, the whole practice changes — not just the individuals. They start applying the same reasoning frameworks, using the same clinical language, and reinforcing each other between sessions.

Each physio also gets to hear how their colleagues would approach a case differently. That stress-tests their own reasoning in a way individual mentoring cannot replicate.

Clinic owners retain visibility into the team's development through session summaries — without the mentoring itself losing confidentiality.
